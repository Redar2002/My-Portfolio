## Problem

Educational guidance and planning rely on a lot of changing information: programmes, schools, paths. The team needed a central web tool they could evolve without rewriting everything.

## Technical choices and trade-offs

- **Lumen rather than full Laravel.** A lightweight micro-framework suited to a pure API, at the cost of features you add yourself (sessions, views).
- **Separate API and front end.** The React front end consumes JSON from the API: each side evolves independently, but CORS and authentication must be handled.
- **One module per domain.** Each functional domain has its own module, which eases maintenance and onboarding.
